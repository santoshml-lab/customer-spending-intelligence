## 🧠 Overview

An AI-powered business intelligence system that analyzes customer spending behavior using machine learning and provides actionable insights for market analysis, revenue optimization, and decision-making.

---

## 🚀 Features

- 🔍 Customer Segmentation using KMeans Clustering  
- 💰 Financial Health Score  
- 📊 Revenue Potential Estimation  
- 🎯 ROI Calculation  
- 🧠 AI-driven Insights  
- 📈 Interactive Dashboard  

---

## 🛠 Tech Stack

- Python  
- Streamlit  
- Scikit-learn  
- Pandas  
- NumPy  
- Plotly  

---

## 📊 How It Works

1. User inputs customer data  
2. Feature engineering (spending ratio)  
3. KMeans clustering segments customers  
4. System generates:
   - Customer type  
   - Financial score  
   - Risk level  
   - Business recommendation
